## The problem

Solace PubSub+ is an event broker: systems publish messages, and queues hold them until a consumer takes them.
When an integration misbehaves, the first question is often "what is actually sitting on that queue?"
The broker's web console lists queued messages but not what is in them, and consuming a message to read it changes the very thing you are investigating.

## What it does

The extension adds a **Find Messages** button to the console's Messages Queued tab.
It browses the queue without consuming anything and shows each message's payload and user properties inline, with a button to copy them.

## What I have built as lead maintainer

The extension began in 2021 as a proof of concept by another Solace community member, in a repository that Solace manages.
I joined in December 2023 and became its lead maintainer: I build its features, review and merge other people's changes, and publish each release to the Chrome Web Store.

- **Connection manager.** Several saved connections, a connection test, automatic choice of the connection that matches the open broker, search, and JSON import and export that merges.
- **Credentials kept safe.** Saved passwords are encrypted with AES-GCM through the browser's Web Crypto API, behind a key with strength rules. The key itself is never stored.
- **Fewer permissions.** Access is limited to Solace Cloud and local broker addresses.
- **Local and self-hosted brokers.** Support for brokers on localhost and your own servers, alongside Solace Cloud.
- **Better viewing.** User properties, copy to clipboard, a fix for duplicated messages, and scrolling for large payloads.
- **A rebuild for the store.** The code moved to shared ES modules with the Solace library in the service worker, and the manifest was brought in line with Chrome Web Store rules.
